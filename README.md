# Radmir Scripts — обновление скриптов через лаунчер

Репозиторий со скриптами и библиотеками для **RADMIR CRMP**, которые раздаются игрокам
через лаунчер **Scripts By YaroRage** (`Launcher.exe`).

## Как это работает

`Launcher.exe`, который игрок кладёт в свою папку, при запуске:

1. Скачивает `manifest.json` с GitHub (этот репозиторий).
2. Сравнивает его с локальной версией.
3. Показывает список новых/изменённых файлов и обновляет их по выбору.
4. При необходимости доустанавливает компоненты (MoonLoader, SAMPFUNCS).

## Для игрока

1. Скачайте свежий `Launcher.exe` из [Releases](../../releases).
2. Положите его в свою игровую папку (например, `C:\Games\RADMIR Games`).
3. Запустите `Launcher.exe`.
4. Отметьте нужные файлы и нажмите **Обновить**.

Лаунчер сам найдёт папку игры (где лежит `gta_sa.exe`) или предложит выбрать.

## Автостарт (mafk)

`mafk_watchdog\AutoStart.exe` — маленькая панель у игрока для управления авто-игроком (mafk):

- **Включить/Выключить автозапуск игры** — создаёт/убирает файл-флаг `mafk_on.flag`
  рядом с `gta_sa.exe` и запускает/останавливает watchdog (автологин + автоперезапуск при вылете).
- **Автозапуск при входе в Windows** — включает/выключает запуск watchdog вместе с системой.
- **Включить/Выключить mafk в конфиге** — правит `MafkEnabled` в `AutoLoginSettings.ini`.

Запускается из скрытой папки `mafk_watchdog\` (не удаляйте её).

## Для автора (публикация обновлений)

Утилиты лежат в соседней папке `launcher\` (не в этом репозитории):

| Скрипт          | Что делает |
|-----------------|------------|
| `watch.ps1`     | Интерактивный инструмент: следит за папками игры и базы, показывает изменения и пушит выбранные в репозиторий (запуск через `watch.bat`). |
| `generate-manifest.ps1` | Заново генерирует `manifest.json` по содержимому `repo\`. |
| `build.ps1`     | Собирает `AutoUpdaterYR.exe` и `AutoStart.exe` (single-file) в `publish\` и `dist\`. |

### Типичный цикл публикации

1. Добавили/изменили скрипт в игре или базе.
2. Открыли `watch.bat` -> выбрали изменения -> пуш в репозиторий.
3. Собрали лаунчер: `build.ps1`.
4. Выложили свежий `Launcher.exe` в [Releases](../../releases).

## Структура

- `manifest.json` — манифест: список файлов (путь, sha256, размер, куда класть) и компонентов.
- `moonloader/` — Lua-скрипты и библиотеки (раскладываются в корень игры).
- `*.asi`, `*.dll` и др. — корневые файлы игры.
- `mafk_watchdog/` — служебные файлы базы.
